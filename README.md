# Computer Vision 101

## Goal of this repo:

I made this repo mainly as a starting point for me to learn a bit of computer vision. I am going to be using openCV as the main tool.


### img\_ops/

This directory has the basic operations that you can make on a static image: isolate color, detect edges, classify shapes ...


### vid\_ops/

This directory only has a script that detects motion using your webcam. It uses nearly all the techniques that were done in the img\_ops/


## Projects/

This directory has some basic hands-on projects to practice what I learned in the previous two dirs
